## Now building: Anti-Alpha Lab

[![Anti-Alpha Lab](https://anti-alpha-lab.tonghowen.chatgpt.site/og.png)](https://anti-alpha-lab.tonghowen.chatgpt.site)

**Can the internet's worst traders become a quant factor?**

[Anti-Alpha Lab](https://github.com/HowenT/anti-alpha-lab) is an open-source, paper-only research project using public prediction-market transactions. Version 0.1 screens 20 recent public wallets across 946 closed positions, anonymises their identifiers, shrinks noisy return estimates, and publishes the resulting watchlist.

The provocative headline comes with a conservative research contract: no real capital, no identity hunting, explicit limitations, and no alpha claim before forward out-of-sample evidence.
